# Unlimited Energy: The Fusion Miracle Just Happened!

Generated by news-hypervideo CLI.

**Style**: breaking | **Duration**: ~36s | **Photos**: 3

## Quick Commands

```bash
# Preview in browser (hot reload):
npx hyperframes preview

# Render (standard quality):
npx hyperframes render --output ../fusion-energy-breakthrough.mp4

# Draft render (fast for iteration):
npx hyperframes render --output ../fusion-energy-breakthrough-draft.mp4 --quality draft

# Add cinematic transition:
npx hyperframes add cinematic-zoom
# Then reference it in index.html as a sub-composition
```
